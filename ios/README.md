# iOS: исходники прототипа

Создано на Windows. Есть экран анкеты, камера и медиатека, хранение адреса и ключа OpenAI, тестовая отправка фото на HTTPS-адрес сервера. Отправка и камера не проверены на iPhone; сервер пока не генерирует. Подключение Kaggle и каталог в UI не реализованы. OpenAI-ключ не используется.

## Сборка через GitHub Actions

Файл `.github/workflows/ios-build.yml` запускает macOS runner, создаёт Xcode-проект и собирает неподписанный `FashionStylist-unsigned.ipa`. Он автоматически запускается при изменениях в `ios/`, а также вручную через Actions → iOS unsigned build → Run workflow. Артефакт можно скачать со страницы запуска.

Важно: workflow ещё не запускался. Сборка без подписи проверяет компиляцию, но **не устанавливается на обычный iPhone и не загружается в TestFlight**. Для TestFlight нужны действующая подписка/доступ к команде, сертификат, provisioning и App Store Connect. Секреты никогда не помещать в репозиторий; платные действия не производить без разрешения.

Чтобы workflow появился на GitHub, содержимое `ai-fashion-stylist` должно находиться в **корне GitHub-репозитория** (включая скрытую папку `.github`). В текущей папке нет Git-репозитория, и ничего никуда не отправлено. GitHub Actions может иметь ограничения доступности, квоты или расходов в зависимости от типа репозитория, организации и тарифа — проверить в своём аккаунте до запуска. Результат и возможные расходы не гарантированы.

## Сборка на Mac в будущем

Понадобятся Mac с Xcode, XcodeGen (отдельный сторонний инструмент), Apple Account и доступ к своему iPhone. Установить XcodeGen по его официальной инструкции, затем из этой папки:

```sh
xcodegen generate
open FashionStylist.xcodeproj
```

В Xcode выбрать собственный уникальный Bundle Identifier и команду подписи, затем запустить на устройстве. Бесплатный Personal Team ограничен 7-дневным сроком профиля. Для TestFlight нужна платная программа Apple или доступ к уже существующей команде. Эти команды здесь не запускались и их результат не гарантирован.

Адрес в настройках может быть задан позднее. Не размещать сервер в интернете без HTTPS и авторизации. Не отправлять фотографии или ключ в неизвестный сервер. Ни одно подключение не обходится без проверки условий и разрешения на расходы.
