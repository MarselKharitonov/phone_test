# AI Fashion Stylist

Статус: исследование и проектирование, не готовый продукт. Дата проверки: 18.11.2026.

Задача — получить фотографию клиента в конкретном продаваемом SKU, не меняя рамки кадра. Первый рынок — РФ. Предусмотрены два варианта генерации: GPT Image и модель VTON в Kaggle для тестов с последующим переносом на платный GPU. Их доступность и пригодность требуют проверки. Продакшен заблокирован отсутствием подтверждённых прав на каталог и доступного владельцу платёжного маршрута. Фотографическая примерка в этом репозитории **пока не реализована**.

## Веб-прототип с ручной примеркой

Откройте `web/index.html` в браузере. Страница формирует промпт из параметров, позволяет предварительно просмотреть фото и вручную загрузить результат из чата. Фотографии не отправляются с этой страницы на сервер; при перезагрузке они исчезают. Шрифты загружаются с Google Fonts (при отсутствии сети используются системные). Генерации, каталога, автоматического подбора размеров и платёжного API нет. Фотографии в чат нужно прикладывать отдельно, соблюдая применимые условия и права.
