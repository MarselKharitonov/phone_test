## Решение на сегодня

Нулевой бюджет может позволить тесты в Kaggle при доступности аккаунта и соблюдении условий, но **не гарантирует** реальный SKU, успешную примерку или платный запуск. Первый рынок — РФ; запуск зависит от подходящего статуса владельца и одобрения провайдера. Международный план отложен.

## Решение владельца: GPT Image и Kaggle

Обновление 19.11.2026: [FASHN Human Parser](https://github.com/fashn-AI/fashn-human-parser#license) ссылается на [NVIDIA Source Code License for SegFormer](https://github.com/NVlabs/SegFormer/blob/master/LICENSE), пункт 3.3 которого ограничивает использование исследованиями/оценкой в некоммерческих целях. Не считать весь pipeline коммерчески разрешённым, несмотря на Apache-2.0 для модели FASHN v1.5.

Проверено 18.11.2026: [OpenAI: поддерживаемые страны API](https://help.openai.com/en/articles/5347006-openai-api-supported-countries-and-territories) не включает РФ и предупреждает, что предоставление доступа вне перечисленных территорий может привести к блокировке. Поэтому GPT Image **нельзя считать допустимым для запуска российского сервиса** без выяснения применимости условий к конкретной схеме; иностранный сервер или счёт сами по себе не подтверждают допустимость. Ограничения не обходить. [Документация изображений](https://platform.openai.com/docs/guides/image-generation) описывает редактирование изображений и возможную необходимость верификации организации. Цена и доступность аккаунта для владельца не проверены.

[Условия Kaggle](https://www.kaggle.com/terms) не удалось прочитать автоматически; применение, квоты, приватность и региональная доступность не подтверждены. Рассматривать Kaggle только как экспериментальную среду, не API производства; использовать тестовые данные с правами, не публиковать персональные фото и не обещать бесплатную ёмкость. Перед передачей даже тестовых фото проверить приватность notebook/dataset/output и внешних зависимостей. Для реальных пользователей дополнительно проверить законодательство РФ о персональных данных, включая локализацию и трансграничную передачу.

Необходимый правовой gate: источник данных и разрешение на хранение, трансформацию, передачу внешнему обработчику и показ результатов отдельно по каждой программе/SKU; также обработка фотографий и мерок, трансграничная передача, сроки и запросы на удаление. Не считать молчание правообладателя согласием.
