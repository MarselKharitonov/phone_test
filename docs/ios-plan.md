# iPhone MVP: ограничения и схема

План, не готовая сборка. Уточнено владельцем: домашний компьютер выступит сервером; адрес сервера пользователь задаёт в настройках приложения, а не зашивается в код.

## Установка

По [Apple](https://developer.apple.com/help/account/basics/about-your-developer-account/) бесплатная Personal Team позволяет установить приложение на собственное устройство через Xcode; provisioning истекает через 7 дней, потребуется пересборка и переустановка. Это не TestFlight. Для TestFlight нужна платная Apple Developer Program или доступ к команде с ней: [Apple указывает $99 в год](https://developer.apple.com/programs/). Актуальные доступность и способы оплаты для владельца проверять у Apple; оплату не производить.

Сборка и установка посредством Xcode требуют Mac; на текущем Windows-компьютере подписать и проверить приложение с помощью Xcode нельзя.

## Предлагаемая архитектура

iPhone → домашний API → экспериментальный Kaggle notebook → домашний API → iPhone. Запуск ноутбука и получение output — кандидаты через [официальный Kaggle CLI](https://github.com/Kaggle/kaggle-cli). Это пакетный процесс, а не подтверждённый realtime API; время, GPU-квоты, приватность, отсутствие утечек через datasets/output и соответствие условиям ещё проверить. Передавать только согласованные тестовые фото. Не считать схему работоспособной до end-to-end теста.

Настройки: опциональный URL сервера, диагностика соединения; без него генерация недоступна. Тестовый режим ограничить доверенной домашней сетью с аутентификацией, не открывать сервер в интернет. Для публичного доступа требуется HTTPS, аутентификация, авторизация, безопасное хранение и анализ угроз; IP сам по себе не обеспечивает безопасность, а HTTP передаёт фото и токены открытым текстом.

Ключ OpenAI API — ввод вручную на iPhone, хранение в Keychain; не путать с ChatGPT Plus. Какие именно негенеративные AI-функции вызывать и какова их стоимость — определить до включения. Не встраивать собственный секрет в приложение, не отправлять его на домашний сервер без отдельного решения. Проверять региональную применимость условий поставщика.

Необходимые проверки до тестирования: ограничение загрузок и контента; очистка метаданных; явное согласие на передачу сторонним сервисам; изоляция задач и результатов; удаление файлов на сервере и Kaggle; проверка лицензии фото товаров и модели; видимые зоны, сохранение исходного кадра и ручной QC. Никаких гарантий реалистичной посадки.
