# Подключение Kaggle: проверка

`python kaggle_experiment/check_connection.py` выполняет только авторизацию и запрос списка своих notebook; не запускает GPU и ничего не публикует. Нужен установленный официальный пакет `kaggle` и настроенные локально учётные данные.

На рабочем компьютере соединение через официальный Python API проверено успешно. Не переносите файл ключа в репозиторий и не отправляйте его в чат. На домашнем сервере настройка выполняется отдельно. Заготовки запуска генерации пока нет: сначала нужно определить безопасный способ передачи тестовых изображений и проверить приватность набора, notebook и output в конкретном аккаунте. Запуск Kaggle CLI может создавать версии notebook и датасетов, и удаление локальных файлов не гарантирует их удаления с платформы.
