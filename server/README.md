# Домашний сервер: заготовка

Пока **не запущен и не является HTTP-сервером**. Здесь только память задач и интерфейс провайдеров. Реального сетевого API, очереди, хранения, TTL, авторизации, передачи фотографий или генерации нет. Не открывать его в интернет и не использовать данные реальных пользователей.

`KaggleAdapter` намеренно отклоняет отправку: не проверены приватность, изоляция задач, удаление данных и применимость условий. `FakeAdapter` возвращает ошибку, не изображение. Для полноценного сервера ещё нужны проверка изображения декодированием, нормализация EXIF, контроль размеров выходного кадра, TLS, аутентификация, журналирование без секретов и надёжная очередь. Все эти меры описаны в `docs/server-contract.md`.

`stylist/sizing.py` сопоставляет только введённые мерки тела с таблицами тела конкретных вариантов; неподтверждённые размеры изделия не конвертируются в размеры тела. Это заготовка без подключения к UI и каталогу.
